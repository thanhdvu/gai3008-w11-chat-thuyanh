# 11주차 포트폴리오 기록

1. **만든 것**
   - 채팅 UI, 사용자/AI 말풍선, 입력창, 타이핑 점 3개, `AnimatedList` 삽입, 오류 말풍선과 재시도.

2. **막힌 것**
   - 응답이 즉시 나타나면 앱이 멈췄는지 알기 어렵고, 오류가 화면 밖으로 사라지면 다음 행동을 알 수 없었다.

3. **해결**
   - sending/typing/error 상태를 분리하고, 200ms 타이핑 점과 250ms 삽입 애니메이션을 적용했다. 오류는 `AnimatedSwitcher` 안에 남기고 마지막 질문을 다시 시도한다.

4. **다음에 개선할 것**
   - 12주차에는 API client 구현을 실제 Baryon proxy와 연결하고, key는 `dart_defines.json`으로만 주입한다.

5. **증거**
   - 커밋 3개: UI → 상태·애니메이션 → 오류·기록.
   - 검증: `flutter analyze`, `flutter test`; 수동 확인 항목은 성공 응답, 401/429/500/timeout, retry, 키보드, Reduce Motion이다.

## 제출 전 보완 및 검증

- 빈 대화로 시작하며 빈 상태를 실제로 표시한다.
- newest-first 목록과 `insertItem(0)`을 일치시켜 새 말풍선에 250ms 삽입 효과를 적용한다.
- 앱 → HTTP proxy 구조를 사용한다. `node proxy/server.mjs`로 키 없이 실행한다.
- proxy는 401/429/500/timeout을 처음 한 번 발생시키고 retry 시 성공하여 복구를 시연한다.
- 429 재시도 대기는 오류 종류를 기준으로 1초 → 2초 적용한다.
- Flutter 자동검증 15개 통과: 오류 5종 복구, 질문 중복 방지, 실제 응답 timeout, Reduce Motion, 키보드 inset 포함.
- HTTP proxy 실통신 확인: 401/429/500 각각 첫 실패 → retry 200 통과.
- 실제 Android 기기/에뮬레이터는 연결되지 않아 물리 키보드·OS 설정 조작은 미검증이다. 해당 동작은 Flutter 위젯 테스트로 확인했다.
